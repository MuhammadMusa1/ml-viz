# Перевод сайта на таджикский

Тексты сайта выгружены в `i18n/ru/` — 31 файл JSON: каждая страница урока, главная, библиотека учебников, каталог уроков (названия, «Типичные ошибки», «Что дальше», словарь терминов) и шапка сайта. Перевод кладётся в `i18n/tg/` с теми же именами файлов.

Правила перевода для Gemini — в [PROMPT.md](PROMPT.md).

## Вариант 1. Antigravity (удобнее всего)

Antigravity — редактор Google с агентом Gemini — уже установлен на этом компьютере.

1. Откройте в Antigravity папку `D:\ML\ml\ml-viz`.
2. Напишите агенту: *«Выполни задание из i18n/PROMPT.md: переведи все файлы i18n/ru/*.json в i18n/tg/»*.
3. Когда он закончит, скажите об этом Claude — он проверит и вставит перевод.

## Вариант 2. Gemini в браузере

1. Откройте gemini.google.com, прикрепите `PROMPT.md` и 3–5 файлов из `i18n/ru/` (начните с `ui.json` и `catalog.json`).
2. Попросите вернуть каждый файл отдельным блоком JSON.
3. Сохраните каждый ответ в `i18n/tg/` под тем же именем (например, `i18n/tg/page.knn.json`).
4. Повторите для остальных файлов в том же чате, чтобы Gemini держал одни и те же термины.

## После перевода

```
node tools/i18n.js import tg
```

Команда проверит каждый файл (те же ключи, HTML-теги и подстановки `{…}`) и вставит перевод в страницы. Затем в `assets/core.js` в `LANGS` добавляется `'tg'` — и в шапке появится переключатель «Рус / Тоҷ».

Перевод стоит показать человеку, который хорошо знает таджикский: машинный перевод терминов бывает неточным.

Учебник (`book/ml`, `book/ml2`) сюда не входит: его переводят в Word и собирают заново командой `python tools/build_book.py`. Слова-примеры в уроках 17–18 (эмбеддинги, attention, токены, температура) остаются русскими: модели на этих страницах посчитаны для русских слов.
