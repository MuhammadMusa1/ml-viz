# Задание для Gemini: перевод «Лаборатории ML» на таджикский

Ты переводишь интерактивный учебный сайт по машинному обучению для школьников 12–17 лет с русского на **таджикский язык (кириллица)**.

## Что сделать

Для каждого файла `i18n/ru/<имя>.json` создай файл `i18n/tg/<имя>.json` **с теми же ключами**, где значения переведены на таджикский. Ключи не меняй, не добавляй и не удаляй (единственное исключение — ключи `glossary.N.re`, см. ниже). Ответ — только валидный JSON, без пояснений.

Сначала переведи `ui.json` и `catalog.json`, потом страницы `page.*.json`. Прежде чем начать страницы, составь словарь терминов (см. «Единые термины») и дальше держись его во всех файлах.

## Правила

1. **Стиль.** Простой живой язык для подростка, обращение на «ту» (как «ты» в русском тексте). Короткие фразы. Перевод по смыслу, а не дословно.
2. **HTML-теги не трогай.** `<b>`, `<i>`, `<br>`, `<ol>`, `<li>`, `<code>`, `<p>`, `<ul>`, `<sub>`, `&nbsp;` и все атрибуты остаются точно как в оригинале и в том же количестве. Переводишь только текст между тегами.
3. **Подстановки `{n}`, `{k}`, `{t}` и любые `{слово}` не трогай** — оставь ровно такими же и в том же количестве.
4. **Код не переводи.** Всё внутри `<code>…</code>` — это код Python: оставь его как есть, переводи только комментарии после `#` в коде.
5. **Оставь без перевода:** названия видов пингвинов (Adelie, Chinstrap, Gentoo); названия библиотек и функций (sklearn, Pipeline, StandardScaler, KNN, Gradio, Colab, Hugging Face, MNIST, softmax, ReLU и т. п.); английские термины, которые в русском тексте стоят латиницей (accuracy, precision, recall, train, validation, test, baseline, Gini, MAE, MSE, max_depth, learning rate, transfer learning, AutoML, overfitting) — их оставляй латиницей, а русское пояснение рядом переводи; числа, проценты, эмодзи, знаки «›», «→», «·», «—».
6. **Примеры-данные уроков 17–18 оставь по-русски.** На страницах `page.tokens`, `page.embeddings`, `page.attention`, `page.temperature` модели работают с русскими словами и предложениями. Слова и фразы в кавычках «…», которые являются примерами из данных (например «он», «пингвин», «Пингвин съел рыбу…», «король − мужчина + женщина»), не переводи — переводи только объяснения вокруг них.
7. **Строки со знаком `|`** — это списки: сохрани то же число частей через `|`.
8. **Ключи `glossary.N.re_ru`** — это шаблон для поиска русского слова в тексте. Не переводи его, а **добавь рядом ключ `glossary.N.re`** с таким же шаблоном для таджикского слова: основа слова и окончания через `[а-яёӣӯқғҳҷ]*`. Пример: если термин «признак» ты переводишь как «аломат», то `"glossary.0.re": "аломат[а-яёӣӯқғҳҷ]*"`. Для английских терминов (accuracy, train и т. п.) просто скопируй русский шаблон. Сам ключ `glossary.N.re_ru` в ответ включать не нужно.

## Единые термины

Одно понятие — одно слово на всех страницах. Перед переводом страниц составь таблицу «русский термин → таджикский» для слов: признак, модель, обучение, точность, пингвин, вид, урок, игра, раунд, проверка, экзамен, пробный экзамен, учёба, ленивая модель, стандартное отклонение, карта решений, выброс, пропуск, корреляция, дерево решений, лес, нейрон, нейросеть, эпоха, токен, эмбеддинг, внимание, температура, переобучение, утечка данных, кросс-валидация, аугментация, приложение, учебник. Используй её во всех файлах.

## Проверка

После перевода ничего не нужно проверять руками: команда `node tools/i18n.js import tg` сама сверит ключи, теги и подстановки и скажет, если что-то не так.
