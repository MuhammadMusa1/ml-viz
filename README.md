# Лаборатория ML

Интерактивные визуализации машинного обучения для школьников к курсу ML (24 урока).
Работает без установки и без интернета.

## Как открыть

- **В классе без интернета:** скопируйте папку на флешку и откройте `index.html` двойным кликом.
- **В интернете:** выложите папку на GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Структура

```
index.html            главная, строится из каталога
assets/style.css      общие стили
assets/core.js        общие функции (canvas, язык, генератор случайных чисел)
assets/catalog.js     карта курса: какие страницы есть и к каким урокам
data/penguins.js      Palmer Penguins + разбиение train/test как в sklearn
data/penguins_raw.js  исходные 344 строки с пропусками (урок 4)
data/*.js             учебные данные страниц: картинки, тексты, слова, предложения
viz/<тема>/index.html страницы визуализаций
tools/                Python-скрипты: пересборка данных и сверка с sklearn
book/                 учебники: book/ml, book/ml2 собираются из Word командой python tools/build_book.py
notebooks/            ноутбуки Colab к главам 1–33 (кнопки «Открыть в Colab» на сайте)
CLAUDE.md             правила проекта для Claude Code
PROMPTS.md            готовые промпты для следующих страниц
```

Данные: Palmer Penguins (Horst, Hill, Gorman, 2020), лицензия CC0.
