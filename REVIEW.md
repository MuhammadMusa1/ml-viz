## A. Неточности: ученик выучит неправильно — исправить обязательно

| # | Где | Проблема | Исправление |
|---|---|---|---|
| A1 | train-test (игра «Найди лучшее K»), pipeline (3 запуска на test), knn («какое K выбрал бы») | Параметр подбирают **по test** и тут же переигрывают — закрепляется вредный навык. Оговорка про validation спрятана в свёрнутом блоке. | Вариант 1 (лучше): на train-test добавить третью линию **validation** (часть train), K выбирать по ней, test открывать один раз. Вариант 2 (только текст): после экзамена — «Мы подсмотрели в test. В жизни K выбирают по отдельной проверочной части (validation), а test открывают один раз в конце». |
| A2 | все страницы | «Точность» в русской литературе часто = *precision*. | При первом упоминании: «Точность (accuracy) — доля верных ответов». |
| A3 | train-test | Нет опоры: что значит «93%»? В test 35 Adelie из 69 — модель «всегда Adelie» уже даёт **51%**. Chinstrap всего 11. | В «Для любопытных»: ленивая модель = 51%; при редком виде accuracy обманывает (мостик к уроку 11). |
| A4 | pipeline | «граммы в тысячи раз длиннее миллиметров» — **неверно** (разброс массы ≈ 813 г, клюва ≈ 5.5 мм — примерно в 150 раз). Слово «отклонение» не объяснено. | «Масса у пингвинов отличается на сотни граммов, клюв — на несколько миллиметров. Без масштаба KNN смотрит почти только на массу». Объяснить «стандартное отклонение» простыми словами. |
| A5 | linreg | R² на странице бывает **меньше 0**, а текст говорит «от 0 до 1». | «R² может быть и меньше 0: значит, прямая хуже, чем просто называть среднюю массу». |
| A6 | forest | «у всех ошибки разные», «другие скорее всего ответили верно» — слишком сильно: на границе видов ошибаются многие деревья сразу. Шаг 4 («средняя уверенность») может противоречить строке «за него v из n деревьев». | «Ошибки отчасти разные, случайные промахи сглаживаются; где ошибаются почти все — ошибётся и лес». Пояснить, почему иногда побеждает вид с меньшим числом «рук». |
| A7 | knn | «Почему K лучше брать нечётным?» — при **трёх** видах нечётное K не спасает от ничьей (2-2-1 при K=5). | «Для двух классов нечётное K исключает ничью, для трёх — нет; тогда sklearn берёт вид раньше по алфавиту». |
| A8 | tree, forest, pipeline (игры) | 1 пингвин из 69 = 1.45%. «Ты обыграл модель!» при разнице в 1 — это шум. | Добавить в «Для любопытных»/«Для учителя»: на маленьком test разница в 1–2 пингвина ничего не значит. |
| A9 | код в «Для любопытных» | Сниппеты не запускаются целиком: нет `X`, `y`; на train-test код с `make_pipeline` до урока 10. | Добавить строки загрузки данных или комментарий «как в Colab»; пометка «# подробнее в уроке 10». |

## B. Понятность текстов для школьника

| # | Где | Проблема | Исправление |
|---|---|---|---|
| B1 | все | «Карта решений» нигде не объяснена; «бледные места» в лесу тоже. | Подсказка у флажка: «каждая точка фона окрашена в вид, который модель назвала бы пингвину в этом месте». |
| B2 | knn | Задание «Включи «одинаковый масштаб»», а кнопка — «Привести признаки к одному масштабу» → ребёнок не найдёт. | Цитировать подпись кнопки дословно. |

| B4 | tree | Gini появляется на экране раньше объяснения; «чистота» — наоборот, Gini это смешанность. Счётчики «0 · 0 · 3» без меток видов. | «Gini — смешанность группы: 0 = все одного вида». Цветные метки у счётчиков. |
| B5 | все | Англ. термины без перевода: Train/Test в заголовке, `max_depth`, CART в сообщении игры, StandardScaler на станции. | «Train / Test (учёба и экзамен)», «Глубина дерева (max_depth)», «Масштаб (StandardScaler)», в игре без «CART». |
| B6 | pipeline | «Ошибка: учить масштаб на всех данных» — странно «включать ошибку»; слово «утечка» есть только у учителя. «Забыть шаг невозможно» — слишком сильно. | «Подсмотреть в test при масштабировании (утечка данных)»; назвать «утечку» в шаге 4; «Конвейер сам следит за порядком шагов». |
| B7 | все | Один и тот же смысл назван по-разному: «Точность на новых пингвинах / на test / Лес на test / конвейера»; «обучающие / учебные / известные». | Единый словарь: «Точность на test (экзамен)», «train (обучающие)», «стандартное отклонение». |

## Что хорошо и не трогать
- Порядок «аналогия → график → панель», аналогии бытовые и сквозные («билеты», «20 вопросов», «рюкзак», «фабрика»).
- «Переобучение» появляется только после того, как ученик увидел проблему сам.
- «Попробуй сам» почти везде наводит на вывод и решается по странице.
- Формулы верны; честно показаны мягкое голосование леса, масштаб только по train, разница sklearn `Pipeline` / HF `pipeline`.
- Цвета видов одинаковые везде; ошибки отмечены не только цветом (крестик).
