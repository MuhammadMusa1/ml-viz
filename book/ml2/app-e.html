Приложение E. Шпаргалка по MLflow

Отслеживание экспериментов из фазы 6 — «лабораторный журнал» для ML.

Логирование запуска

import mlflow, mlflow.sklearn

mlflow.set_experiment("мой_проект")

with mlflow.start_run():
    model = ...  # обучаем
    mlflow.log_param("lr", 0.001)          # параметр
    mlflow.log_param("n_estimators", 100)
    mlflow.log_metric("accuracy", 0.87)    # метрика
    mlflow.log_metric("f1", 0.82)
    mlflow.sklearn.log_model(model, "model")  # сама модель

Что логировать

КодЧто делает
log_param("имя", значение)Параметр (lr, глубина, число деревьев)
log_metric("имя", число)Метрика (accuracy, f1, loss)
log_model(model, "model")Сохранить саму модель
log_artifact("file.png")Сохранить файл (график, отчёт)

Зачем это 🎯

Когда экспериментов десятки, MLflow отвечает на вопрос «какой запуск был лучшим и с какими параметрами?» точно, а не «где-то был хороший вариант». Вместе с random_state, Git и Docker даёт полную воспроизводимость.
