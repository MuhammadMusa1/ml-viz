Глава 12. Мини-проект: детектор объектов с интерфейсом

Цель главы 🎯

После этой главы ты соберёшь законченный проект компьютерного зрения: детекция объектов + веб-интерфейс + проверка модели через Grad-CAM, и оформишь его для портфолио.

Вторая фаза завершается настоящим продуктом, объединяющим всё: детекцию (или классификацию), веб-интерфейс из тома 1 (Gradio) и, для сильных, проверку модели через Grad-CAM. Это проект, который эффектно смотрится в портфолио и на защите.

Что делаем

Веб-приложение, куда пользователь загружает фото, а модель находит и обводит на нём объекты (или классифицирует, если выбрал классификацию). Гибкость проекта — в развилке путей:

Базовый путь 🟢

Детектор на готовой YOLO: загружаешь фото → приложение показывает его с рамками и списком найденных объектов. Впечатляюще и достижимо для всех.

Продвинутый путь 🔵

Свой классификатор (дообученный ResNet из главы 8) + Grad-CAM: приложение показывает не только класс, но и тепловую карту «куда смотрела сеть». Это уникальный проект уровня выше среднего.

Каркас: YOLO + Gradio

Базовый путь собирается быстро — детекция готовой моделью и интерфейс Gradio (знакомый по тому 1).

import gradio as gr
from ultralytics import YOLO

model = YOLO("yolov8n.pt")

def detect(image):
    results = model(image)
    annotated = results[0].plot()   # картинка с рамками (numpy)
    # список найденного
    found = [f"{model.names[int(b.cls)]} ({float(b.conf):.2f})"
             for b in results[0].boxes]
    return annotated, "\n".join(found) or "Ничего не найдено"

demo = gr.Interface(
    fn=detect,
    inputs=gr.Image(type="numpy", label="Загрузи фото"),
    outputs=[gr.Image(label="Найденные объекты"),
             gr.Textbox(label="Список")],
    title="Детектор объектов",
)
demo.launch(share=True)

Ожидаемый результат: рабочее приложение с публичной ссылкой — загружаешь фото, видишь рамки.

Защита проекта

Как и в томе 1, подготовь короткий рассказ: какую задачу решает, на чём построено (YOLO / свой ResNet), демонстрация вживую, что узнал. Для продвинутого пути обязательно покажи Grad-CAM — «смотрите, сеть действительно смотрит на объект» — это производит сильное впечатление и показывает глубину понимания.

Главная мысль фазы 2 🎯

Ты прошёл путь от «что на картинке» до «что, где и почему»: понял идею глубоких сетей (ResNet), научился дообучать их под свои данные с профессиональной аугментацией, освоил детекцию и сегментацию и научился заглядывать внутрь сети через Grad-CAM. И собрал из этого живой продукт. Компьютерное зрение перестало быть магией — теперь это твой инструмент.
