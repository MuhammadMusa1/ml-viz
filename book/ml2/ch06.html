Глава 6. Мини-проект: модель из тома 1 на PyTorch

Первая фаза завершается проектом, который связывает том 1 и том 2: возьмём задачу, которую ты уже решал на Keras, и решим её заново на PyTorch — целиком, со всеми навыками фазы. Это закрепит паттерн PyTorch и покажет, что ты уже владеешь инструментом всерьёз.

Задача проекта

Возьми любую задачу классификации из тома 1 — MNIST, свой датасет фото или табличные данные (Titanic). Цель — пройти полный путь на PyTorch, применив всё из фазы 1: свой Dataset, модель через nn.Module, цикл обучения, GPU, кривые обучения, Dropout, early stopping и сохранение.

Чек-лист проекта

Полный проект PyTorch собирается из кирпичиков, которые ты освоил в главах 1–5. Пройди по списку — это и есть скелет любого проекта на PyTorch.

  1. Данные: свой Dataset (или готовый) + DataLoader с батчами, деление на train/val/test.
  2. Модель: класс nn.Module с __init__ и forward, при желании Dropout и BatchNorm.
  3. Обучение: цикл из пяти шагов, перенос на GPU (.to(device)).
  4. Контроль: кривые обучения train/val, early stopping по validation.
  5. Сохранение: лучшая модель в state_dict.
  6. Оценка: точность на test (один раз, в конце) + сравнение с версией из тома 1.

Каркас проекта

Вот скелет, который остаётся наполнить своими данными и архитектурой. Он объединяет всю фазу 1 в один рабочий файл.

# --- Мини-настройка: данные и сеть из глав 2-3 ---
import torch, torch.nn as nn
from torchvision import datasets, transforms
from torch.utils.data import random_split
_full = datasets.MNIST(root="data", train=True, download=True,
                      transform=transforms.ToTensor())
train_ds, val_ds = random_split(_full, [55000, 5000])
class Net(nn.Module):                       # та же сеть, что в главе 3
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(28*28, 128)
        self.fc2 = nn.Linear(128, 10)
        self.relu = nn.ReLU()
    def forward(self, x):
        x = self.flatten(x)
        x = self.relu(self.fc1(x))
        return self.fc2(x)
# --- конец мини-настройки ---

import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import DataLoader

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 1. Данные (свой Dataset или готовый) + DataLoader
train_loader = DataLoader(train_ds, batch_size=64, shuffle=True)
val_loader   = DataLoader(val_ds, batch_size=64)

# 2. Модель
model = Net().to(device)
loss_fn = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 3-5. Обучение с валидацией, ранней остановкой и сохранением
best_val, wait, patience = float("inf"), 0, 3
for epoch in range(100):
    model.train()
    for X, y in train_loader:
        X, y = X.to(device), y.to(device)
        optimizer.zero_grad()
        loss = loss_fn(model(X), y)
        loss.backward()
        optimizer.step()

    # валидация
    model.eval()
    val_loss = 0
    with torch.no_grad():
        for X, y in val_loader:
            X, y = X.to(device), y.to(device)
            val_loss += loss_fn(model(X), y).item()

    if val_loss < best_val:
        best_val, wait = val_loss, 0
        torch.save(model.state_dict(), "best.pt")
    else:
        wait += 1
        if wait >= patience:
            print(f"Стоп на эпохе {epoch+1}"); break

Прочитай этот каркас — в нём нет ни одной строки, которую ты бы не разобрал в главах 1–5. Это и есть «взрослый» PyTorch: не магия, а привычный паттерн из понятных шагов.

Сравни с томом 1

Завершив проект, честно сравни: та же задача на Keras (том 1) и на PyTorch (том 2). Точность должна быть примерно одинаковой — алгоритм тот же. Что изменилось: кода больше, но и контроля больше. Запиши свои выводы: где PyTorch оказался удобнее, где Keras проще, что понравилось тебе.

Главная мысль фазы 1 🎯

Ты перешёл с «магического» model.fit() на полный контроль: сам готовишь данные, описываешь модель, пишешь цикл обучения, борешься с переобучением и сохраняешь результат. PyTorch больше не пугает — это просто набор понятных шагов. На этом фундаменте построена вся современная работа с нейросетями, и следующие фазы (компьютерное зрение, эмбеддинги, LLM) опираются именно на него.
