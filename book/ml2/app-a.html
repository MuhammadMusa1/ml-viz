Цикл обучения (сердце PyTorch)

optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(epochs):
    model.train()
    for X, y in train_loader:
        X, y = X.to(device), y.to(device)
        optimizer.zero_grad()      # 1. обнулить градиенты
        pred = model(X)            # 2. прогноз
        loss = loss_fn(pred, y)    # 3. ошибка
        loss.backward()            # 4. градиенты
        optimizer.step()           # 5. шаг

Золотые правила PyTorch 🎯

Порядок цикла всегда: zero_grad → forward → loss → backward → step.

Модель и данные — на одном устройстве (.to(device) для обоих).

На обучении model.train(), на оценке model.eval() + torch.no_grad().

Сохраняй state_dict (веса), а не модель целиком; код модели держи рядом.
