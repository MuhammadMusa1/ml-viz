Что такое память диалога

Аналогия: собеседник, который помнит разговор 💡

Без памяти ассистент как человек с амнезией: каждый вопрос — с чистого листа, он забыл, о чём вы только что говорили. Спросишь «а сколько это стоит?» — он не поймёт, о чём речь. Память диалога — это когда ассистент помнит предыдущие реплики и понимает контекст: «это» относится к тому, что обсуждали. Технически — мы просто передаём модели историю разговора вместе с новым вопросом (помнишь context window из тома 1 — история должна в него влезать).

Развилка путей

Базовый путь 🟢

Чат-ассистент с RAG и памятью: отвечает по твоим документам и помнит разговор. Интерфейс Gradio Chatbot. Полноценный впечатляющий продукт.

Продвинутый путь 🔵

Добавь инструменты (калькулятор, поиск), streaming и оценку качества (глава 23). Ассистент, который отвечает по документам, помнит контекст, пользуется инструментами и печатает вживую — уровень настоящего продукта.

Каркас: чат с памятью и RAG

import gradio as gr

# db — векторная база из главы 20 (твои документы)
# llm — модель (Ollama локально или облачная)

def respond(message, history):
    # 1. RAG: находим релевантные фрагменты по вопросу
    docs = db.similarity_search(message, k=3)
    context = "\n".join(d.page_content for d in docs)

    # 2. ПАМЯТЬ: собираем историю диалога + контекст + новый вопрос
    prompt = f"Контекст из документов:\n{context}\n\n"
    for user, bot in history:              # прошлые реплики
        prompt += f"Пользователь: {user}\nАссистент: {bot}\n"
    prompt += f"Пользователь: {message}\nАссистент:"

    # 3. Ответ модели по контексту И истории
    return llm(prompt)

# Gradio Chatbot сам хранит history и рисует чат
gr.ChatInterface(respond, title="Мой ИИ-ассистент").launch(share=True)

Ожидаемый результат: чат по публичной ссылке, который отвечает по твоим документам и помнит беседу.
