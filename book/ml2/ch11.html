Глава 11. Заглянуть в мысли сети: Grad-CAM

Цель главы 🎯

После этой главы ты сможешь объяснить, зачем визуализировать внимание CNN, применить Grad-CAM для получения тепловой карты «куда смотрит сеть» и использовать это для проверки модели на разумность.

Сеть говорит «это волк» — но почему? Что именно на картинке её убедило? В томе 1 мы обсуждали объяснимый ИИ (SHAP) для табличных данных. Для картинок есть свой мощный инструмент — Grad-CAM. Он рисует тепловую карту: какие области изображения сильнее всего повлияли на решение. Это перекликается с этикой и XAI из тома 1 и учит критическому мышлению.

Аналогия: подсветить, куда смотрел ученик 💡

Grad-CAM — как если бы ты мог подсветить на фотографии те места, куда смотрел ученик, отвечая на вопрос. Сказал «это собака» — и подсветка легла на морду и уши: отлично, смотрел куда надо. Но если подсветка легла на траву в углу, а не на животное, — тревожный знак: сеть «угадала» по фону, а не по объекту. Grad-CAM превращает чёрный ящик в стеклянный, показывая тепловой картой области внимания.

Знаменитая история про волков и хаски

Классический случай из исследований: сеть отлично отличала волков от хаски — пока Grad-CAM не показал, что она смотрит не на животных, а на СНЕГ на фоне. В обучающих фото волки почти всегда были на снегу, а хаски — нет. Сеть выучила «есть снег → волк» вместо признаков самого животного. На новых фото без снега она бы позорно провалилась. Без Grad-CAM эту ловушку не заметили бы. Вот почему «заглянуть в мысли сети» — не игрушка, а инструмент контроля качества.

Grad-CAM на практике

Идея под капотом: Grad-CAM смотрит, как сильно каждая область последнего свёрточного слоя повлияла на итоговое решение (через градиенты — привет, глава 1), и строит из этого тепловую карту. Реализовать можно готовой библиотекой в несколько строк.

# --- Мини-настройка: модель и картинка для примера (вместо ResNet из главы 8) ---
import torch, numpy as np
from torchvision.models import resnet18
model = resnet18(weights=None)          # архитектура ResNet, веса не качаем
model.eval()
input_tensor = torch.rand(1, 3, 224, 224)               # картинка-заглушка
rgb_img = np.random.rand(224, 224, 3).astype("float32") # для наложения карты
# --- конец мини-настройки ---

# pip install grad-cam
from pytorch_grad_cam import GradCAM
from pytorch_grad_cam.utils.image import show_cam_on_image
import numpy as np

# model — наш дообученный ResNet из главы 8
# целевой слой — последний свёрточный блок
cam = GradCAM(model=model, target_layers=[model.layer4[-1]])

# grayscale_cam — тепловая карта для картинки input_tensor
grayscale_cam = cam(input_tensor=input_tensor)[0]

# Накладываем карту на исходное изображение
visualization = show_cam_on_image(rgb_img, grayscale_cam, use_rgb=True)
# visualization можно показать: красное = "сюда сеть смотрела сильнее всего"

Ожидаемый результат: фото с наложенной тепловой картой — красные зоны = максимум внимания сети.

Зачем это в реальной работе ℹ️

Grad-CAM применяют, чтобы (1) проверить, что модель смотрит на объект, а не на фон/артефакт; (2) отладить ошибки — понять, почему сеть путает классы; (3) объяснить решение человеку (врачу, эксперту), которому важно доверие к модели; (4) найти предвзятость (глава об этике тома 1) — не смотрит ли сеть на нерелевантные признаки. Это профессиональный навык, а не украшение.
