«Мой RAG готов?»

Проверка RAG ℹ️

Документы порезаны осмысленно (куски — законченные мысли, есть overlap).

Эмбеддинг-модель подходит языку (многоязычная для русского).

Retrieval находит нужные фрагменты (проверено на вопросах-перефразировках).

Ответ опирается на найденное, не выдумывает (faithfulness).

Модель признаёт, когда ответа в документах нет.

Оценено на наборе вопросов, а не «на глаз».

«Модель к деплою готова?»

Проверка перед выпуском ℹ️

Модель сохранена (state_dict / joblib) вместе с кодом архитектуры.

Обёрнута в API (FastAPI) или интерфейс (Gradio), проверена на новых данных.

Окружение зафиксировано (requirements.txt, при возможности Docker).

Есть базовые тесты (форма выхода, диапазон, устойчивость к пропускам).

Продуман мониторинг дрейфа (хотя бы вручную).

Эксперименты записаны (MLflow) — знаешь, какая версия лучшая и почему.
