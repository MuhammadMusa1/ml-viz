Приложение J. Глоссарий терминов уровня 2

Новые термины тома 2. Термины тома 1 (train/test, Pipeline, эмбеддинг и др.) — в глоссарии первого тома.

ТерминЗначение
Batch (батч)Пачка примеров, которую подают модели за один шаг обучения.
BatchNormСлой, нормирующий значения внутри сети; ускоряет и стабилизирует обучение.
CI/CDАвтопроверка кода при каждом изменении (CI) и автовыпуск (CD).
Cross-encoder (кросс-энкодер)Модель, оценивающая пару «запрос+документ» вместе; точнее, но медленнее.
DataLoaderИнструмент PyTorch, выдающий данные батчами и перемешивающий их.
Data drift (дрейф данных)Постепенное расхождение свежих данных с обучающими; модель «стареет».
Detection (детекция)Задача «что и где»: найти объекты и обвести рамками.
DockerУпаковка приложения с окружением в контейнер; «работает у всех».
DropoutСлучайное отключение нейронов при обучении против переобучения.
DuckDBЛёгкая база для SQL прямо в Python, без сервера.
Early stoppingОстановка обучения, когда validation-ошибка перестала падать.
Embedding-модельМодель, превращающая текст в вектор смысла (Sentence Transformers).
FastAPIБиблиотека для выпуска модели как API для других программ.
Fine-tuningДообучение готовой модели под свою задачу.
Function callingСпособность LLM вызывать внешние инструменты.
Grad-CAMТепловая карта «куда смотрит» свёрточная сеть при решении.
GNNГрафовая нейросеть — учится на данных-связях (соцсети, молекулы).
LangChainБиблиотека-конструктор приложений с LLM (в т.ч. RAG).
LoRA / QLoRAЭкономное дообучение LLM: учим маленькие адаптеры, не всю модель.
MLflowЖурнал экспериментов: параметры, метрики, модели.
Мульти-агентыНесколько LLM-агентов с ролями, решающих задачу вместе.
OllamaИнструмент запуска LLM локально, офлайн и приватно.
polars / daskЗамена pandas: polars — быстрее, dask — данные больше памяти.
Pull request (PR)Заявка влить свою ветку в main после код-ревью.
RAGОтветы LLM по найденным в твоих документах фрагментам.
RAGASИнструмент автоматической оценки качества RAG.
ResNetГлубокая сеть с остаточными связями (skip connections).
Segmentation (сегментация)Разметка объекта по пикселям, а не рамкой.
StreamingПотоковая выдача ответа LLM по словам, как в ChatGPT.
ТензорМногомерный массив чисел в PyTorch; умеет GPU и градиенты.
ChunkingНарезка документов на куски для RAG.
АвтоградАвтоматический расчёт градиентов в PyTorch (.backward()).
Векторная базаХранилище эмбеддингов с быстрым поиском ближайших (Chroma).
КвантованиеСнижение точности чисел модели ради лёгкости и скорости.
Feature storeОбщий склад признаков для команды и разных моделей.
YOLOБыстрая модель детекции объектов («смотрим один раз»).
