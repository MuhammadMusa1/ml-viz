Инженерия из фазы 6: упаковка (Docker) и командная работа (Git).

Git: базовые команды

КодЧто делает
git initЗавести репозиторий
git add . / git commit -m "..."Добавить и сохранить
git push / git pullОтправить / подтянуть
git checkout -b feature/xСоздать ветку и перейти
git merge / git statusСлить ветку / статус

Git: командный процесс

Цикл командной работы 🎯

1. Своя ветка под задачу: git checkout -b feature/задача

2. Работаешь, коммитишь, пушишь ветку

3. На GitHub открываешь pull request

4. Коллеги делают код-ревью, ты правишь

5. После одобрения — merge в main

Правило: никогда не коммить прямо в main.

Docker: Dockerfile

FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

Docker: команды

КодЧто делает
docker build -t имя .Собрать образ по Dockerfile
docker run -p 8000:8000 имяЗапустить контейнер
docker psСписок запущенных контейнеров
docker imagesСписок собранных образов

Три понятия Docker ℹ️

Dockerfile — рецепт (как собрать). Образ — готовый слепок (собран по рецепту). Контейнер — запущенный экземпляр образа. Рецепт → замороженное блюдо → разогретое блюдо.
