Глава 30. Когда pandas не тянет: polars и dask

Цель главы 🎯

После этой главы ты сможешь объяснить, почему pandas не справляется с очень большими данными, и знать, когда брать polars (быстрее) или dask (данные больше памяти).

Pandas прекрасен, но у него есть предел: он загружает все данные в оперативную память и работает в один поток. Когда данных десятки гигабайт, он либо падает с нехваткой памяти, либо еле ползёт. Разберём, чем его заменить и когда.

Аналогия: один грузчик, бригада, склад с доставкой 💡

Pandas — один грузчик, который таскает коробки по одной и должен уместить все на своём столе (в памяти). Polars — бригада грузчиков, работающих параллельно (использует все ядра процессора): те же коробки, но в разы быстрее. Dask — служба, которая не тащит весь склад к тебе, а обрабатывает коробки прямо на складе по частям (данные, которые не влезают в память, читаются кусками с диска). Разные инструменты под разный масштаб задачи.

Три инструмента под три масштаба

ИнструментКогда братьКлючевое отличие
pandasДанные влезают в память (до ~1–2 ГБ)Просто, привычно, огромная экосистема
polarsВлезают, но pandas медленный (гигабайты)В разы быстрее: параллелизм + оптимизация
daskНе влезают в память (десятки ГБ+)Обрабатывает данные кусками, не загружая всё

Polars: тот же смысл, другой синтаксис

Polars намеренно похож на pandas, но быстрее в разы за счёт использования всех ядер процессора и умной оптимизации запросов. Переучиваться почти не нужно.

# pip install polars
import polars as pl

df = pl.read_csv("big_data.csv")   # читается быстрее pandas

# Знакомые операции — фильтр, группировка
result = (df
    .filter(pl.col("price") > 100)
    .group_by("city")
    .agg(pl.col("price").mean().alias("avg_price"))
    .sort("avg_price", descending=True)
)
print(result)

Полезно знать ℹ️

Синтаксис polars чуть отличается от pandas (методы через точку цепочкой), но логика та же: фильтр, группировка, агрегат. На данных в несколько гигабайт polars часто в 5–10 раз быстрее pandas на той же машине — просто потому, что задействует все ядра, а pandas работает в одно. Если pandas «задумался» надолго — попробуй polars.

Dask: данные больше памяти

Когда данные физически не влезают в оперативную память, ни pandas, ни polars не помогут — нужен dask. Он делит данные на куски, обрабатывает их по очереди и собирает результат, поэтому может работать с данными больше объёма памяти. Синтаксис почти как у pandas.

# pip install dask
import dask.dataframe as dd

# Читает по кускам, не загружая всё в память сразу
df = dd.read_csv("huge_data_*.csv")   # даже много файлов разом

# Операции как в pandas, но выполняются "лениво"
result = df[df["price"] > 100].groupby("city")["price"].mean()

# Вычисление запускается только по .compute()
print(result.compute())

Внимание: не усложняй раньше времени ⚠️

Начинай с pandas — он покрывает подавляющее большинство учебных и реальных задач. Переходи на polars, только когда pandas реально тормозит на твоих данных, и на dask — только когда данные не влезают в память. Тащить dask на датасет в 10 МБ — это стрелять из пушки по воробьям: сложнее код, больше багов, ноль выгоды. Инструмент должен соответствовать масштабу задачи.
