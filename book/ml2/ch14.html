Глава 14. Sentence Transformers: эмбеддинги за одну строку

Цель главы 🎯

После этой главы ты сможешь получать эмбеддинги предложений готовой моделью Sentence Transformers, измерять близость реальных текстов и объяснить, почему эмбеддинг предложения — не то же самое, что эмбеддинги отдельных слов.

Хватит выдумывать векторы — получим настоящие. Библиотека Sentence Transformers — сегодняшний стандарт для эмбеддингов текста: одна строка, и предложение превращается в вектор смысла. Это рабочая лошадка всего современного NLP.

Слово, предложение, документ

Аналогия: смысл фразы — не сумма слов 💡

Ранние эмбеддинги (word2vec из тома 1) кодировали отдельные слова. Но смысл предложения — не просто сумма слов: «собака укусила человека» и «человек укусил собаку» состоят из одних слов, а смысл противоположный. Sentence Transformers кодируют предложение целиком, с учётом порядка и контекста, в один вектор. Поэтому они называются sentence (предложенческими) — работают на уровне мысли, а не слова.

Эмбеддинги на практике

# pip install sentence-transformers
from sentence_transformers import SentenceTransformer

# Лёгкая быстрая модель — хороший выбор по умолчанию
model = SentenceTransformer("all-MiniLM-L6-v2")

sentences = [
    "Как обучить нейросеть?",
    "Каким образом тренируют модель ИИ?",   # тот же смысл
    "Какая погода в Душанбе завтра?",       # другой смысл
]

# Одна строка — и каждое предложение стало вектором
embeddings = model.encode(sentences)
print(embeddings.shape)   # (3, 384) — 3 вектора по 384 числа

Метод .encode() — вся магия. Модель уже обучена компанией на огромных данных; ты просто пользуешься. Каждое предложение стало вектором из 384 чисел (у этой модели). Теперь сравним их по смыслу косинусной близостью из прошлой главы.

from sentence_transformers import util

# Косинусная близость между всеми парами
sim = util.cos_sim(embeddings, embeddings)
print(sim)
# Ожидаем: предложения 0 и 1 близки (тот же смысл),
# а 2 далеко от обоих (про погоду)

Первые два предложения окажутся близки по смыслу, третье — далеко, хотя слова везде разные.

Полезно знать ℹ️

util.cos_sim из библиотеки делает то же, что твоя функция cosine из главы 13, но сразу для всех пар и быстро. Размер вектора (384, 768, 1024…) зависит от модели: больше — обычно точнее, но медленнее и «тяжелее» хранить. all-MiniLM-L6-v2 (384) — золотая середина для старта: быстрая, лёгкая, достаточно точная.

Задания

Базовый путь 🟢

Установи sentence-transformers, возьми all-MiniLM-L6-v2 и получи эмбеддинги 5 своих фраз (2–3 близких по смыслу, остальные разные). Посчитай попарную близость через util.cos_sim. Нашла ли модель смысловые пары, несмотря на разные слова?

Продвинутый путь 🔵

Проверь пример «собака укусила человека» vs «человек укусил собаку» vs «пёс атаковал прохожего». Как модель оценивает их близость? Улавливает ли она разницу в порядке слов и синонимию одновременно? Опиши, что удивило.
