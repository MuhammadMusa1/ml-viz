Учебник

Приложение G. Банк проектов уровня 2

Идеи проектов посложнее, чем в томе 1, — по фазам. Командные помечены отдельно, с ролями (для финального проекта фазы 6).

PyTorch и зрение (фазы 1–2)

  • Классификатор своих фото на дообученном ResNet + Grad-CAM (показать, куда смотрит сеть).
  • Детектор объектов на YOLO: сосчитать людей/машины на фото или видео.
  • Переписать любимую модель тома 1 на PyTorch с полным циклом обучения.

NLP и эмбеддинги (фаза 3)

  • Семантический поиск по своим конспектам/книге (найти по смыслу).
  • Определитель дубликатов вопросов (fine-tuning эмбеддинг-модели).
  • Сравнение эмбеддинг-моделей на русских текстах: мини-исследование.

LLM: RAG и агенты (фаза 4)

  • ИИ-ассистент по учебнику/правилам с памятью диалога.
  • Агент с инструментами: калькулятор + поиск + твой RAG.
  • RAG на локальной модели (Ollama) — полностью офлайн и приватно.

Данные (фаза 5)

  • Свой датасет парсингом (цены, отзывы) → анализ → модель.
  • Прогноз по данным из API (погода, курсы НБТ) с признаками из дат.
  • Дашборд-исследование: собрать, очистить, показать инсайты.

Командные проекты (фаза 6)

Роли: Data · ML · Backend · Frontend 🎯

Умный помощник по школьным материалам: RAG-ассистент от сбора конспектов до веб-чата.

Сервис предсказания цен: парсинг → модель в Pipeline → API в Docker → веб-интерфейс.

Классификатор/детектор как продукт: модель → FastAPI → мониторинг → интерфейс с загрузкой фото.

Анализатор отзывов: сбор данных → NLP-модель → дашборд с тональностью.

В каждом: Git с ветками и PR, README с ролями, деплой по ссылке, защита командой.
