Глава 19. Мини-проект: умный поиск по своим документам

Цель главы 🎯

После этой главы ты соберёшь законченный проект семантического поиска по собственной коллекции документов с веб-интерфейсом и оформишь его для портфолио.

Третья фаза завершается проектом, который объединяет всё: эмбеддинги, векторную базу, семантический поиск и (для сильных) переранжирование. Ты соберёшь умный поиск по своим текстам — тот самый механизм, что стоит за корпоративными базами знаний и лежит в основе RAG следующей фазы.

Что делаем

Веб-приложение: пользователь задаёт вопрос обычными словами, а система находит самые релевантные по смыслу фрагменты из твоей коллекции документов и показывает их. Гибкость — в развилке:

Базовый путь 🟢

Семантический поиск на Chroma + Gradio: загружаешь свои тексты, задаёшь вопрос, получаешь топ-3 релевантных фрагмента. Полноценный работающий продукт.

Продвинутый путь 🔵

Добавь связку retrieve → rerank (кросс-энкодер из главы 17) и выбор многоязычной модели для русского. Сравни качество с базовой версией и покажи разницу в README.

Каркас проекта

import gradio as gr
import chromadb
from chromadb.utils import embedding_functions

# Векторная база с многоязычной моделью (хорошо для русского)
ef = embedding_functions.SentenceTransformerEmbeddingFunction(
    model_name="paraphrase-multilingual-MiniLM-L12-v2")
client = chromadb.Client()
col = client.create_collection("docs", embedding_function=ef)

# Загружаем свои документы (список абзацев)
my_docs = [ ... ]   # твои тексты
col.add(documents=my_docs, ids=[str(i) for i in range(len(my_docs))])

def search(query):
    res = col.query(query_texts=[query], n_results=3)
    return "\n\n---\n\n".join(res["documents"][0])

demo = gr.Interface(
    fn=search,
    inputs=gr.Textbox(label="Твой вопрос"),
    outputs=gr.Textbox(label="Найденные фрагменты"),
    title="Умный поиск по моим документам",
)
demo.launch(share=True)

Ожидаемый результат: приложение, куда вводишь вопрос и получаешь релевантные по смыслу фрагменты.

Идеи для коллекции документов

  • Свои конспекты по предмету — поиск ответа на вопрос по учёбе.
  • Правила школы / кружка — быстрый ответ «а можно ли…».
  • Любимая книга или статья, разбитая на абзацы, — поиск по содержанию.
  • FAQ по игре или приложению — поиск решения проблемы.

Чек-лист проекта

Проект готов, если 🎯

Загружена своя коллекция (хотя бы 20–30 фрагментов).

Поиск находит релевантное по смыслу, а не по точным словам (проверено перефразировками).

Есть веб-интерфейс и публичная ссылка.

Есть README: что за поиск, по каким данным, примеры удачных запросов.

🔵 Для продвинутого пути: добавлен reranking и/или сравнение моделей.

Главная мысль фазы 3 🎯

Ты прошёл путь от «подсчёта слов» до системы, которая понимает смысл: получаешь эмбеддинги готовыми моделями, осознанно их выбираешь, строишь семантический поиск по векторным базам, уточняешь кросс-энкодерами и дообучаешь под свою область. Это и есть современный NLP. А главное — теперь у тебя есть всё, чтобы в следующей фазе собрать полноценный RAG: умный поиск плюс языковая модель.
