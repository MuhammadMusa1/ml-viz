Приложение C. Шпаргалка по SQL и DuckDB

SQL из фазы 5 через DuckDB — SQL прямо в Python. Четыре кита покрывают большинство задач.

DuckDB: запуск

import duckdb
# SQL прямо по DataFrame df или по CSV
result = duckdb.sql("SELECT * FROM df WHERE age > 30").df()
# По файлу без загрузки в pandas:
duckdb.sql("SELECT * FROM 'data.csv' LIMIT 5").df()

JOIN: соединение таблиц

SELECT c.name, SUM(o.amount) AS total
FROM customers c
JOIN orders o ON c.id = o.customer_id
GROUP BY c.name
ORDER BY total DESC
