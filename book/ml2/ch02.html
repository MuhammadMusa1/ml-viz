Глава 2. Данные правильно: Dataset и DataLoader

Цель главы 🎯

После этой главы ты сможешь объяснить, зачем данные подают модели пачками (батчами), использовать готовый DataLoader и написать свой класс Dataset для собственных данных.

Прежде чем обучать сеть, данные нужно правильно подать. В томе 1 Keras делал это за нас. В PyTorch есть два инструмента, которые стоит понять один раз и пользоваться всегда: Dataset (как достать один пример) и DataLoader (как выдавать примеры пачками и перемешивать).

Зачем батчи: не всё сразу

Аналогия: есть слона по кусочкам 💡

Нельзя запихнуть в модель миллион картинок разом — не хватит памяти (особенно на GPU). Данные подают пачками (батчами) по 32–128 штук: модель смотрит пачку, чуть подкручивает веса, берёт следующую. Это как есть слона по кусочкам, а не целиком. Бонус: обучение по батчам ещё и стабильнее, чем по одному примеру, и быстрее, чем по всем данным сразу.

DataLoader на готовом датасете

Начнём с готового датасета (знакомый MNIST из тома 1) — PyTorch умеет грузить его сам. DataLoader оборачивает данные и выдаёт их батчами, перемешивая на каждой эпохе.

import torch
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# Превращаем картинки в тензоры и нормируем (как /255 в томе 1)
transform = transforms.ToTensor()

# Готовый датасет MNIST (скачается автоматически)
train_ds = datasets.MNIST(root="data", train=True,
                          download=True, transform=transform)

# DataLoader: батчи по 64, перемешивание на train
train_loader = DataLoader(train_ds, batch_size=64, shuffle=True)

# Посмотрим на один батч
images, labels = next(iter(train_loader))
print(images.shape)   # torch.Size([64, 1, 28, 28]) — 64 картинки

Форма батча [64, 1, 28, 28] читается так: 64 картинки, 1 канал (чёрно-белые), 28×28 пикселей. Параметр shuffle=True перемешивает данные каждую эпоху — это важно, чтобы модель не запоминала порядок примеров.

Свой Dataset для своих данных

Готовые датасеты — хорошо, но реальная сила в том, чтобы подать свои данные. Для этого пишут класс Dataset с тремя методами. Это выглядит сложнее, чем есть: по сути ты отвечаешь на два вопроса — «сколько у меня примеров?» и «как достать пример номер i?».

# --- Мини-данные, чтобы пример запускался сам ---
import numpy as np
X_train = np.random.rand(200, 4).astype("float32")  # 200 примеров, 4 признака
y_train = np.random.randint(0, 3, size=200)          # 3 класса

from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, X, y):
        # сохраняем данные как тензоры
        self.X = torch.tensor(X, dtype=torch.float32)
        self.y = torch.tensor(y, dtype=torch.long)

    def __len__(self):
        return len(self.X)          # сколько всего примеров

    def __getitem__(self, i):
        return self.X[i], self.y[i]  # как достать пример номер i

# Использование — как с готовым датасетом:
ds = MyDataset(X_train, y_train)
loader = DataLoader(ds, batch_size=32, shuffle=True)

Полезно знать ℹ️

Три метода Dataset — это контракт с PyTorch: __init__ (подготовить данные), __len__ (сколько их) и __getitem__ (выдать один по индексу). Понял эти три метода — сможешь подать в PyTorch что угодно: таблицы, картинки из папок, тексты. Это ключевой навык для работы со своими данными в томе 2.
