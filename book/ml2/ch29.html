Глава 29. Добываем данные: парсинг из интернета

Цель главы 🎯

После этой главы ты сможешь извлекать данные с веб-страниц (парсинг) базовыми инструментами и, главное, делать это этично и по правилам — уважая сайты и закон.

Часто нужных данных нет ни в одном датасете — но они есть на веб-страницах. Парсинг (web scraping) — это автоматический сбор данных с сайтов. Мощный навык, но с ним приходит ответственность: собирать данные нужно этично и легально. Об этом — в первую очередь.

Сначала об этике и правилах ⚠️

Проверь robots.txt сайта (адрес/robots.txt) — там сказано, что парсить можно, а что нельзя. Уважай это.

Читай условия использования сайта — некоторые прямо запрещают автоматический сбор.

Не перегружай сайт: делай паузы между запросами (time.sleep), не шли сотни запросов в секунду — это как DDoS.

Не собирай персональные данные людей без согласия — это нарушение приватности и часто закона.

Если есть официальный API — используй его вместо парсинга. Это правильнее и надёжнее.

Аналогия: гость в чужом доме 💡

Парсинг — это как прийти в гости. Вежливый гость смотрит, куда его пускают (robots.txt), не хватает лишнего, не приходит толпой и по сто раз (паузы между запросами) и не роется в личных вещах хозяев (персональные данные). Невежливый гость, который выносит всё подряд и ломится без спроса, быстро получает бан по IP, а иногда и иск. Собирай данные так, как хотел бы, чтобы собирали с твоего сайта.

Как устроен парсинг

Два шага: (1) скачать HTML страницы (библиотека requests), (2) вытащить из HTML нужные данные (библиотека BeautifulSoup). HTML — это дерево тегов, и мы находим в нём элементы по названию тега или классу.

# pip install requests beautifulsoup4
import requests
from bs4 import BeautifulSoup
import time

# 1. Скачиваем страницу (с вежливым User-Agent)
url = "https://example.com/products"
html = requests.get(url, headers={"User-Agent": "MyLearningBot"}).text

# 2. Разбираем HTML и достаём данные
soup = BeautifulSoup(html, "html.parser")

# Например, все заголовки товаров с классом "title"
for item in soup.find_all("h2", class_="title"):
    print(item.get_text(strip=True))

time.sleep(1)   # пауза перед следующим запросом — уважаем сайт

Полезно знать ℹ️

find_all("тег", class_="класс") находит все элементы нужного типа. Чтобы понять, какие теги и классы искать, открой страницу в браузере, нажми правой кнопкой на нужный элемент → «Просмотреть код» — увидишь структуру HTML. Для сложных сайтов, где данные подгружаются скриптами, requests не хватит — там нужны инструменты вроде Selenium/Playwright (это уже продвинутая тема).

От страницы к датасету

Собранные данные складывают в список словарей и превращают в DataFrame — получается твой собственный датасет, готовый для анализа и обучения модели (как в томе 1).

import pandas as pd

data = []
for item in soup.find_all("div", class_="product"):
    data.append({
        "name": item.find("h2").get_text(strip=True),
        "price": item.find("span", class_="price").get_text(strip=True),
    })

df = pd.DataFrame(data)     # твой собственный датасет!
df.to_csv("my_scraped_data.csv", index=False)
