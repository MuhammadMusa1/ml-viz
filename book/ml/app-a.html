Учебник

Приложение A. Мини-справочник по Python

Короткое напоминание основ Python, которые нужны в этой книге. Если что-то из этого незнакомо — стоит потратить пару часов на вводный курс Python, прежде чем двигаться дальше.

Переменные и типы данных

x = 5              # целое число (int)
pi = 3.14          # дробное число (float)
name = "Аня"       # строка (str)
is_ready = True    # логический тип (bool): True / False
nothing = None     # "ничего", пустое значение

Списки и словари

# Список — упорядоченный набор элементов
nums = [10, 20, 30]
nums.append(40)         # добавить в конец -> [10,20,30,40]
print(nums[0])          # первый элемент -> 10
print(nums[-1])         # последний элемент -> 40
print(len(nums))        # длина списка -> 4

# Словарь — пары "ключ: значение"
student = {"имя": "Аня", "возраст": 15}
print(student["имя"])   # обращение по ключу -> Аня
student["класс"] = 9    # добавить новую пару

Условия

score = 75
if score >= 90:
    print("отлично")
elif score >= 60:       # иначе если
    print("хорошо")
else:
    print("надо подтянуть")

Циклы

# Цикл по списку
for n in [1, 2, 3]:
    print(n)

# Цикл по диапазону чисел
for i in range(5):      # 0, 1, 2, 3, 4
    print(i)

# Цикл с условием
count = 0
while count < 3:
    count = count + 1

Функции

# Функция принимает аргументы и возвращает результат
def square(x):
    return x * x

print(square(4))        # -> 16

# Функция с несколькими аргументами и значением по умолчанию
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

print(greet("Аня"))     # -> Привет, Аня!

Полезно знать ℹ️

Запись f"{name}!" называется f-строкой: она подставляет значение переменной прямо в текст. Очень удобно для вывода результатов. Отступы в Python не украшение, а часть синтаксиса — тело цикла, условия и функции сдвигается вправо на 4 пробела.
