Приложение X. Kaggle-соревнование шаг за шагом

Kaggle — лучшая площадка, чтобы применить навыки на реальных данных и учиться у сильнейших. Разберём полное участие в учебном соревновании от начала до отправки решения — на примере вечной классики «Титаник».

Шаг 1. Регистрация и выбор соревнования

  • Заведи аккаунт на kaggle.com (бесплатно).
  • Начни с раздела Getting Started — там учебные соревнования без давления.
  • «Titanic - Machine Learning from Disaster» — идеальный первый вызов, ты уже знаешь эти данные.

Шаг 2. Пойми задачу и данные

На странице соревнования всегда есть: описание задачи, метрика (по чему оценивают), файлы данных. Для «Титаника»: обучающий файл train.csv (с ответами) и тестовый test.csv (без ответов — их предсказываешь ты). Метрика — accuracy.

import pandas as pd

# Kaggle даёт два файла: с ответами и без
train = pd.read_csv("train.csv")   # есть колонка Survived
test = pd.read_csv("test.csv")     # Survived нужно предсказать

print(train.shape, test.shape)

Шаг 3. Обучи модель (весь курс в действии)

Здесь применяется всё из фаз 1–2: EDA, обработка пропусков, Pipeline, baseline, честная оценка по кросс-валидации. Соревнование — идеальная практика полного цикла.

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

features = ["Pclass", "Sex", "Age", "Fare"]
X = train[features]; y = train["Survived"]

prep = ColumnTransformer([
    ("num", Pipeline([("i", SimpleImputer(strategy="median")),
                      ("s", StandardScaler())]), ["Pclass","Age","Fare"]),
    ("cat", OneHotEncoder(handle_unknown="ignore"), ["Sex"]),
])
model = Pipeline([("prep", prep),
                  ("clf", RandomForestClassifier(random_state=42))])

# Честная оценка ДО отправки
print("CV:", cross_val_score(model, X, y, cv=5).mean().round(3))
model.fit(X, y)

Шаг 4. Сделай предсказание и отправь

Kaggle требует ответ в определённом формате — обычно файл с id и предсказанием. Формируем и отправляем.

# Предсказываем для тестовых данных (которых модель не видела)
test_pred = model.predict(test[features])

# Формируем файл ответа в формате соревнования
submission = pd.DataFrame({
    "PassengerId": test["PassengerId"],
    "Survived": test_pred
})
submission.to_csv("submission.csv", index=False)
# Загрузи submission.csv на страницу соревнования -> увидишь свой результат

Шаг 5. Улучшай и учись у других

После первой отправки ты увидишь свой результат в таблице лидеров. Дальше — самое ценное обучение:

  • Улучшай через feature engineering (глава 26) — на Kaggle это решает больше всего.
  • Подбери гиперпараметры (глава 31) для последних процентов.
  • Читай раздел Code — там участники выкладывают свои решения с объяснениями. Учись у лучших.
  • Читай Discussion — там обсуждают приёмы и идеи.

Внимание: осторожно с таблицей лидеров ⚠️

Не гонись слепо за верхними строчками — там иногда переобучаются под конкретный тест соревнования. Твоя цель как ученика — научиться, а не выжать сотую долю процента. Честная кросс-валидация важнее места в таблице. И помни про этику: не копируй чужие решения молча, учись на них и делай своё.

Почему Kaggle бесценен 🎯

Kaggle даёт то, чего не даёт ни один учебник: реальные грязные данные, честное сравнение с тысячами людей и открытые решения сильнейших специалистов мира. Одно доведённое до конца соревнование учит больше, чем десять прочитанных глав. Начни с «Титаника» — ты к нему полностью готов.
