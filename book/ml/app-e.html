Приложение E. Шпаргалка по Keras (нейросети)

Keras — конструктор нейросетей. Сеть собирается как башня из слоёв, затем компилируется и обучается. Пригодится в фазе 3.

Сеть для таблиц/классификации

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(16, activation="relu", input_shape=(N,)),  # N = число признаков
    Dense(8, activation="relu"),
    Dense(1, activation="sigmoid"),   # да/нет
])
model.compile(optimizer="adam", loss="binary_crossentropy",
              metrics=["accuracy"])
model.fit(X_train, y_train, epochs=10)

Сеть для картинок (как MNIST)

from tensorflow.keras.layers import Flatten, Dense

model = Sequential([
    Flatten(input_shape=(28, 28)),      # картинка -> ряд чисел
    Dense(128, activation="relu"),
    Dense(10, activation="softmax"),    # 10 классов
])
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])

Свёрточная сеть (CNN)

from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential([
    Conv2D(32, (3,3), activation="relu", input_shape=(32,32,3)),
    MaxPooling2D((2,2)),
    Conv2D(64, (3,3), activation="relu"),
    MaxPooling2D((2,2)),
    Flatten(),
    Dense(64, activation="relu"),
    Dense(10, activation="softmax"),
])

Шпаргалка по слоям и настройкам

ЭлементДля чего
DenseОбычный полносвязный слой
Conv2DСвёрточный слой (картинки)
MaxPooling2DУменьшает карту признаков
FlattenРазворачивает картинку в ряд чисел
activation="relu"Активация в скрытых слоях
activation="softmax"Выход: вероятности нескольких классов
activation="sigmoid"Выход: да/нет (0..1)
optimizer="adam"Способ подкрутки весов (по умолчанию)
epochs=10Сколько раз пройти по всем данным
