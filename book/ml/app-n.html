Приложение N. Гид по Google Colab

Google Colab — бесплатная среда для запуска Python прямо в браузере, наш главный инструмент. Ничего устанавливать не нужно, всё считается на серверах Google. Здесь — всё, что нужно знать для комфортной работы.

Начало работы

  • Зайди на colab.research.google.com (нужен аккаунт Google).
  • Нажми «Создать блокнот» — откроется чистый блокнот с ячейками.
  • Код пишется в ячейках; запуск — кнопкой ▶ или сочетанием Shift+Enter.
  • Блокноты сохраняются на твой Google Диск автоматически.

Горячие клавиши

КлавишиДействие
Shift + EnterЗапустить ячейку и перейти к следующей
Ctrl + EnterЗапустить ячейку и остаться на ней
Esc, затем AДобавить ячейку выше
Esc, затем BДобавить ячейку ниже
Esc, затем D, DУдалить ячейку

# Установить библиотеку (! означает команду системе)

# Безопасно хранить API-ключ (значок ключа слева -> "Секреты")
from google.colab import userdata

Бесплатный видеоускоритель (GPU)

Для нейросетей (фаза 3) обучение идёт в разы быстрее на GPU. В Colab он бесплатный: меню «Среда выполнения» → «Сменить среду выполнения» → выбрать «T4 GPU». Для таблиц (фаза 2) GPU не нужен.

Частые вопросы по Colab ℹ️

Сессия сбросилась — Colab отключает неактивные блокноты; просто запусти ячейки заново сверху вниз.

Переменная не найдена — забыл запустить ячейку выше, где она создаётся. Запускай по порядку.

Библиотека пропала после перезапуска — переустанови через !pip install; в Colab окружение сбрасывается.
