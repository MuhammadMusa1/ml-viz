Приложение C. Шпаргалка по визуализации

Графики через Matplotlib и Seaborn. Правило из главы 3: под каждым графиком — вывод словами.

Matplotlib — базовые графики

import matplotlib.pyplot as plt

# Гистограмма (распределение одного признака)
df["Age"].hist(bins=20)
plt.xlabel("Возраст"); plt.ylabel("Количество")
plt.title("Распределение возрастов")
plt.show()

# Линейный график
plt.plot([1,2,3], [10,20,15])
plt.show()

# Диаграмма рассеяния (связь двух признаков)
df.plot.scatter(x="Age", y="Fare")
plt.show()

# Столбчатая диаграмма
df["Sex"].value_counts().plot.bar()
plt.show()

Seaborn — красивые графики

import seaborn as sns

# Тепловая карта корреляций
corr = df.corr(numeric_only=True)
sns.heatmap(corr, annot=True, cmap="coolwarm")
plt.show()

# Ящик с усами (поиск выбросов)
sns.boxplot(x=df["Fare"])
plt.show()

# Распределение с разбивкой по категории
sns.histplot(data=df, x="Age", hue="Survived")
plt.show()

Какой график когда выбирать

ВопросГрафик
Как распределён один признак?Гистограмма (hist)
Связаны ли два числовых признака?Диаграмма рассеяния (scatter)
Что с чем коррелирует?Тепловая карта (heatmap)
Есть ли выбросы?Ящик с усами (boxplot)
Сколько объектов в категориях?Столбчатая (bar)
