Учебник

Приложение S. Краткие итоги по фазам

Сжатые конспекты каждой фазы — для быстрого повторения перед контрольной, проектом или защитой. Одна фаза — одна страница главного. Распечатай и держи под рукой.

Фаза 1 — Данные и ML-мышление

Главное 🎯

ML выводит правила из примеров, а не получает их готовыми.

Три задачи: классификация (категория), регрессия (число), кластеризация (группы без ответов).

С учителем — есть ответы; без учителя — нет.

Датасет: строки — объекты, столбцы — признаки, один столбец — цель.

Pandas = «Excel внутри Python»: head, info, describe, groupby, фильтры.

EDA: гистограмма, scatter, heatmap. Под каждым графиком — вывод словами.

Корреляция ≠ причина. Пропуски и выбросы обрабатывай перед моделью.

Фаза 2 — Классический ML

Главное 🎯

KNN — «сосед»; дерево — «20 вопросов»; лес — «голосование класса»; регрессия — «линия через точки».

train/test: учимся на train, честно проверяем на test. Всегда random_state.

Baseline (DummyClassifier) — обязательная точка отсчёта.

Утечка данных — признак недоступен в реальный момент. Опасна: метрики хорошие, толку нет.

Переобучение: train высоко, test низко. Лечит упрощение модели (max_depth).

Pipeline обязателен: обработка + модель, защита от утечки.

Кросс-валидация надёжнее одного split. Метрика: accuracy врёт на дисбалансе — смотри precision/recall/F1.

Фаза 3 — Нейросети

Главное 🎯

Нейрон — взвешенная сумма входов. Обучение — подкрутка весов, чтобы уменьшить ошибку.

Эпоха — один проход по всем данным. Много эпох = обучение.

Изображение для сети — матрица чисел (пиксели). Делим на 255.

Keras: Sequential + Dense; relu в скрытых, softmax/sigmoid в выходе.

CNN (Conv2D + MaxPooling) учитывает расположение пикселей — точнее на картинках.

Transfer learning: берём готового эксперта (MobileNetV2), замораживаем, доучиваем голову.

Аугментация расширяет маленький датасет. Сеть не «понимает» — может уверенно ошибаться.

Фаза 4 — Большие языковые модели

Главное 🎯

LLM — «умный автодополнитель»: предсказывает следующее слово.

Токены — кусочки текста; эмбеддинги — смысл в числах (похожие слова рядом).

Внимание — модель решает, на какие слова смотреть. Трансформер — буква T в GPT.

Галлюцинации — модель уверенно выдумывает; не проверяет факты. Перепроверяй важное.

Промпт = «задание стажёру»: роль, примеры (few-shot), формат, рассуждение по шагам.

LLM работает без train/test — модель уже обучена. Управляешь промптом.

RAG — дать модели текст-шпаргалку, чтобы отвечала по факту. Береги API-ключ.

Фаза 5 — AutoML и AI-инструменты

Главное 🎯

AutoML — «автопилот»: сам перебирает модели и параметры. Не заменяет понимание.

AutoML не поставит задачу, не заметит утечку, не выберет метрику — это на тебе.

Hugging Face Hub — «магазин» готовых моделей: часто задача уже решена кем-то.

HF pipeline ≠ sklearn Pipeline (разные вещи, одно слово).

Gradio строит веб-интерфейс к модели из Python-функции.

share=True — временная ссылка (72 ч). Spaces — постоянный хостинг (app.py + requirements.txt).

Фаза 6 — Финальный проект

Главное 🎯

Задача маленькая, но законченная. Признаки: ясная цель, доступные данные, показуемый результат.

Питч: задача, данные, результат. Сначала «скелет» (работает целиком), потом улучшения.

Улучшай честно через кросс-валидацию; новые признаки часто важнее смены модели.

Обязательно: Pipeline, baseline, правильная метрика, веб-интерфейс, README.

Защита на 5 минут: проблема → данные → решение → живое демо → вывод.

Объясняй «языком для бабушки». Готовь запасное демо на случай сбоя.

Главная награда — живой продукт своими руками, а не баллы.
