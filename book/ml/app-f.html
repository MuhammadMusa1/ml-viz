Учебник

Приложение F. Справочник по промптам для LLM

Промпт — инструкция для языковой модели, «задание для стажёра». Ниже — приёмы и готовые шаблоны, которые пригодятся в фазе 4 и в собственных проектах с ИИ.

Пять приёмов хорошего промпта

ПриёмКак применить
Роль«Ты — опытный редактор / учитель / аналитик…»
Примеры (few-shot)Покажи 2–3 образца «вход → ответ»
Чёткий формат«Ответь одним словом», «Верни список из 3 пунктов»
Рассуждение по шагам«Объясни ход мысли шаг за шагом»
Заземление (RAG)«Отвечай только по тексту ниже, не выдумывай»

Готовые шаблоны

Классификация тональности

Ты анализируешь отзывы. Определи тональность.
Ответь ОДНИМ словом: позитив, негатив или нейтрально.

Примеры:
«Всё супер» -> позитив
«Кошмар, деньги на ветер» -> негатив

Отзыв: «{текст отзыва}»

Извлечение информации

Извлеки из текста имя, дату и город.
Верни в формате: Имя | Дата | Город.
Если чего-то нет — поставь прочерк.

Текст: «{текст}»

Ответ по документу (RAG)

Ответь на вопрос ТОЛЬКО по тексту ниже.
Если ответа в тексте нет — так и скажи, не выдумывай.

Текст:
{документ}

Вопрос: {вопрос}

Помни про галлюцинации ⚠️

LLM предсказывает правдоподобный текст, а не проверяет факты. Всегда перепроверяй важные цифры, имена и даты. Приём «отвечай только по тексту» (RAG) заметно снижает выдумки, но не убирает их полностью. Критическое мышление при работе с ИИ нужно всегда.

Безопасность API-ключа ⚠️

Ключ API — как пароль от карты. Не пиши его прямо в коде, не выкладывай на GitHub, не показывай на экране. В Colab храни в разделе «Секреты». За утёкший ключ платит владелец.
