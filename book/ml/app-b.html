Приложение B. Шпаргалка по Pandas

Pandas — «Excel внутри Python». Ниже собраны команды, которые покрывают 90% работы с таблицами в этой книге. Держи под рукой во время фазы 1 и любого проекта.

Загрузка и первый взгляд

КодЧто делает
pd.read_csv("file.csv")Загрузить таблицу из CSV-файла
df.head(5)Первые 5 строк
df.tail(5)Последние 5 строк
df.shapeРазмер: (строки, столбцы)
df.info()Типы колонок и число заполненных значений
df.describe()Статистика по числовым колонкам
df.columnsСписок названий колонок

Выбор данных

КодЧто делает
df["Age"]Один столбец
df[["Age", "Sex"]]Несколько столбцов
df.iloc[0]Первая строка по номеру
df[df["Age"] > 18]Фильтр: строки по условию
df[(df["Age"] > 18) & (df["Sex"] == "male")]Фильтр по двум условиям (И)

Группировка и сортировка

КодЧто делает
df.groupby("Sex")["Survived"].mean()Среднее по группам
df.groupby("Pclass").size()Число объектов в каждой группе
df.sort_values("Fare")Сортировка по столбцу (по возрастанию)
df.sort_values("Fare", ascending=False)Сортировка по убыванию
df["Sex"].value_counts()Сколько раз встречается каждое значение

Пропуски и очистка

КодЧто делает
df.isnull().sum()Сколько пропусков в каждом столбце
df.dropna()Удалить строки с пропусками
df["Age"].fillna(df["Age"].median())Заполнить пропуски медианой
df.drop(columns=["Name"])Удалить столбец
df.duplicated().sum()Сколько дубликатов строк

Частая ошибка ⚠️

В фильтрах используй двойное == для сравнения (df["Sex"] == "male"), а не одиночное =. При комбинировании условий каждое оборачивай в скобки и соединяй через & (И) или | (ИЛИ).
