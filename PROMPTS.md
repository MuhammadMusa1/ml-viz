## 1. Урок 6 · Train / Test

```
Сделай страницу viz/train-test/index.html по образцу viz/knn.
Тема урока 6: почему модель нельзя проверять на тех же данных, на которых она училась.
Аналогия: нельзя проверять знания по билетам, которые ты уже видел.

Визуализация: те же пингвины (длина и глубина клюва), KNN.
- Ползунок K от 1 до 50.
- Два больших числа рядом: точность на train и точность на test.
- График двух линий «точность от K» (train и test), текущее K отмечено.
- Переключатель: показывать на графике train-точки, test-точки или обе.
- Игра: «Найди лучшее K» — ученик выбирает K, потом показывается, какое K лучшее на test.

Термин «переобучение» вводи только в блоке «Как это работает»,
ПОСЛЕ того как ученик увидел, что при K=1 на train 100%, а на test меньше.
Сверь числа с sklearn и добавь скрипт tools/check_train_test.py.
Поставь status: 'ready' в catalog.js.
```

## 2. Урок 7 · Дерево решений «20 вопросов»

```
Сделай viz/tree/index.html по образцу viz/knn. Тема урока 7, аналогия: игра «20 вопросов».

Визуализация: пингвины (длина и глубина клюва).
- Ученик сам строит дерево: кликает по графику и ставит вертикальный или горизонтальный разрез.
  После каждого разреза показывай Gini слева и справа и сколько пингвинов каждого вида.
- Кнопка «Пусть построит модель»: настоящий алгоритм CART (Gini, лучший порог по каждому признаку)
  с ползунком max_depth от 1 до 6.
- Справа рисуй само дерево вопросов: «Длина клюва < 42.3?» → да / нет.
- Игра: ученик строит дерево из 3 разрезов, сравниваем его точность на test с деревом модели той же глубины.

Сверь с sklearn DecisionTreeClassifier(criterion='gini', random_state=42), скрипт tools/check_tree.py.
Ничьи порогов решай так же, как sklearn (порог = середина между соседними значениями).
```

## 3. Урок 8 · Линейная регрессия

```
Сделай viz/linreg/index.html. Аналогия: положи линейку через точки так, чтобы ошибок было меньше.
Данные: пингвины, предсказываем массу (body_mass_g) по длине крыла (flipper_length_mm).
- Ученик тянет за два конца прямой мышью. Остатки рисуются вертикальными отрезками,
  а для MSE — квадратиками (площадь = квадрат ошибки).
- Живые MAE, MSE, RMSE, R².
- Кнопка «Лучшая прямая» (метод наименьших квадратов) с анимацией перехода.
- Игра: кто ближе подберёт прямую к оптимальной по MSE.
- Переключатель «Добавить выброс»: перетаскиваемая точка-выброс, видно, как MSE реагирует сильнее MAE.
Сверь коэффициенты с sklearn LinearRegression на train.
```
